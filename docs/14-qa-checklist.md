# QA Checklist & BROWSER QA RULE

## BROWSER QA RULE
After each major page is implemented:
1. Open the running website in the browser.
2. Inspect the page visually.
3. Test desktop.
4. Test tablet.
5. Test mobile.
6. Test navigation.
7. Test buttons and links.
8. Test forms.
9. Test animations.
10. Test scrolling.
11. Check overflow.
12. Check console errors.
13. Check hydration errors.
14. Check broken images.
15. Check accessibility.
16. Check SEO metadata.

**Do NOT only report problems.**
For every issue discovered:
1. Identify the root cause.
2. Fix the implementation.
3. Reload the browser.
4. Re-test the affected area.
5. Continue until the issue is resolved.
*Do not mark a page complete merely because the code compiles.*

## Premium Design Test (Before Finalizing)
- Does this look like a ₹5,000 template? (If yes: REDESIGN)
- Does it look like a generic local roofing website? (If yes: REDESIGN)
- Does it look like a SaaS dashboard? (If yes: REDESIGN)
- Does it look like a construction-company template? (If yes: REDESIGN)
- Does the typography feel premium?
- Does the whitespace feel intentional?
- Does the visual hierarchy feel confident?
- Does the animation feel expensive rather than flashy?
- Does the website communicate trust?
- Does the website make the next action obvious?
- Does the site feel fast?
- Does every section have a reason to exist?
