# SEO Architecture

## Technical SEO Implementation
- **Metadata**: Next.js Metadata API for unique `<title>` and `<meta name="description">` per page.
- **URLs**: Clean, descriptive, canonical URLs (`/services`, not `/services-page`).
- **Sitemap & Robots**: Generate `sitemap.xml` and `robots.txt`.
- **Open Graph & Twitter**: Social sharing metadata configured.
- **Semantic HTML**: `<header>`, `<nav>`, `<main>`, `<section>`, `<footer>`, `<article>`.
- **Heading Hierarchy**: Strictly one `<h1>` per page. Followed logically by `<h2>` and `<h3>`. Do NOT use heading tags just for visual sizing.
- **Images**: `alt` text for all images describing the visual content.

## Structured Data (Schema.org)
Implement JSON-LD:
- `Organization` / `LocalBusiness`
- `WebSite`
- `WebPage`
- `Service`
- `BreadcrumbList`

## Content SEO Strategy
- Naturally incorporate keywords: roofing solutions, residential roofing, commercial roofing, industrial roofing, professional roofing, Palakkad, Kerala.
- NO keyword stuffing. NO unsupported location claims (e.g., "Best in Kerala").
