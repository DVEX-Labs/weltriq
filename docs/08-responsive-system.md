# Responsive System

## Philosophy
Design mobile-first. Do not simply shrink the desktop version. Ensure an intentionally designed mobile experience.

## Breakpoints
Test thoroughly at:
- Mobile: `320px`, `375px`, `390px`, `430px`
- Tablet: `768px`
- Laptop: `1024px`
- Desktop: `1280px`, `1440px`
- Large Desktop: `1920px`

## Mobile-Specific Requirements
- Sticky navigation with a compact menu.
- Large touch targets (min 44x44px) for all buttons and links.
- Optimized typography scales (prevent overly large headers on small screens).
- Vertical layouts for complex desktop interactions (e.g., Process timeline).
- Simplified animations.
- Avoid horizontal overflow (100vw constraints).
- Floating WhatsApp CTA should be subtle and non-blocking if used.
