# Page Specifications

## 1. Home
- **Goal**: Strongest page. High impact, high conversion.
- **Structure**:
  1. Premium Navigation
  2. Hero (Cinematic, clear CTA, brand positioning)
  3. Trust / Positioning Statement
  4. What WELTRIQ Does
  5. Why WELTRIQ (Organized project delivery)
  6. Services Overview
  7. Process / Project Journey (Interactive timeline)
  8. WELTRIQ Promise
  9. Strong CTA
  10. Premium Footer

## 2. Services
- **Structure**: Hero Introduction → Service Categories → Detailed Service Cards → Organized Process → CTA.
- **Data**: Data-driven, consistent card UI.

## 3. About
- **Content**: Use supplied Vision, Mission, and positioning. DO NOT invent company history or numbers.
- **Focus**: Storytelling about organized project-delivery philosophy.

## 4. Blog (Architecture)
- Create `/blog` and `/blog/[slug]`.
- Prepare data layer for Title, Excerpt, Image, Author, Date, Category.
- If no real articles exist, show an intentional empty/coming-soon state. DO NOT use fabricated content or Lorem Ipsum.

## 5. Contact
- **Content**: Use official Address, Phone, Email.
- **Layout**: Info + Enquiry Form + WhatsApp Action + Social placeholders.
- **Rule**: Do not invent additional contact details.

## 6. Projects (Future)
- Architect system for future case studies (Project, Category, Location, Description, Images, Services, Outcome).
- DO NOT invent projects now.
