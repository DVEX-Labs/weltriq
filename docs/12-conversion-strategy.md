# Conversion Strategy

## Funnel Design
Visitor → Understand WELTRIQ → Understand Difference → Understand Process → Trust → See Services → Contact / Enquire

## Call to Action (CTA)
- **Primary CTA**: Contact / Roofing Enquiry
- **Secondary CTAs**: WhatsApp, Phone, Email
- **Language**: Confident, premium language based on brand messaging (e.g., "Let's Build a Roof You Can Trust", "Start Your Roofing Project"). NO aggressive sales language or generic "Contact Us Today!!!".
- **Repetition**: Establish one primary CTA and repeat it strategically across pages.

## Conversion Tests
Within seconds, a visitor must understand:
- **WHAT**: WELTRIQ provides roofing solutions.
- **WHO**: Residential, commercial, industrial customers.
- **HOW**: Professionally managed roofing projects.
- **WHY**: Structured process, accountability, quality control, professional execution.
- **NEXT**: Contact WELTRIQ.

## Lead Generation Forms
- Only ask for reasonably required information.
- Provide strong validation, clear loading/success/error states.
- If backend integration is missing, structure cleanly for future API connection.
