# Information Architecture

## Sitemap
1. **Home** (`/`)
2. **Services** (`/services`)
3. **About** (`/about`)
4. **Blog** (`/blog` and `/blog/[slug]`)
5. **Contact** (`/contact`)
*(Future: Projects `/projects`)*

## Navigation Structure
**Desktop**: Logo | Home | Services | About | Blog | Contact | Primary CTA
**Mobile**: Logo | Menu Button (Hamburger)

## Footer Structure
- Brand Lockup (WELTRIQ + Tagline)
- Links: Navigation, Services, Contact
- Social Media placeholders
- Contact Info (Address, Phone, Email)

## Internal Linking Strategy
- Home → Services
- Home → About
- Home → Contact
- Services → Contact
- Blog → Services (Contextual)
- About → Contact
